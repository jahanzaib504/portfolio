# Jahanzaib Arif Awan — Portfolio

Built with React + Vite, Tailwind CSS, and Framer Motion.

## Run locally
```
npm install
npm run dev
```

## Build for production
```
npm run build
```
Outputs a static site to `dist/` — deploy it anywhere (Netlify, Vercel, GitHub Pages, S3+Cloudflare, etc).

## Edit content
All copy (projects, stats, stack, education, links) lives in `src/data.js` — edit that one file to update the site without touching components.
